# Folded-properties demo

This deck (card) note has frontmatter properties (`author`, `tags`) besides the reserved `deck` key.

In **Live Preview**: press `Cmd/Ctrl+P` → **Toggle fold properties in current file** to fold the properties — for card notes the folded panel is hidden **completely** (WYSIWYG, same as reading view).

Unfold via the same command, or switch to **Source mode** to edit the frontmatter.
